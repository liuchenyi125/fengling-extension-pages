# 风聆Studio 登录助手公开说明页

这是登录助手的公开静态介绍、帮助与隐私政策镜像，用于 Chrome Web Store 的公开资料链接。

- `index.html`：扩展介绍、连接步骤、权限解释与使用帮助。
- `privacy.html`：现有官网隐私政策的静态镜像。
- `style.css`：本地样式，无脚本、外部字体或追踪代码。
- GitHub Pages：从 `main` 根目录发布。

公开内容来源：<https://gnmusic.cn/extension/>、<https://gnmusic.cn/privacy/>（2026-10-04 核对）。

本仓库不包含扩展程序包、风聆Studio私有源码、登录凭据、客户数据或运行缓存。这里只维护公开说明，不是第二套软件工程。
